# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 编队预算

开局前可在「编队预算」编辑器中调整每波追猎者 / 游击者 / 精英体的数量：

- 每种敌人占用预算点数（1 / 2 / 5）并对应威胁值（2 / 4 / 12），编辑器实时预览每波预算、威胁与进入时间线。
- 编队预算决定实际出生序列：配置在开局展开为按绝对进入时间排序的队列，敌人按节奏出队。
- 战场达到同屏上限（180）时，到点的出生任务留在队列等待，而不是丢弃预算，难度不随上限变化。
- 出现负预算、单波超预算或超额精英时，整份配置会被拒绝；合法调整可导入 / 导出 JSON，并保存在浏览器本地。
- 支持导入旧版（v1）固定节奏配置，迁移时按原出生速率与概率展开，保持原来的平均强度。
- 升级冻结期间不消耗出生队列；重新开始会按当前配置重建全新队列，不沿用上一局未完成的出生任务。
- 结算记录携带配置版本、配置 ID 与总威胁值，可在行动档案中按配置区分。
